# 🏦 Banking Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive Banking Analytics Dashboard developed using **Power BI**. It provides insights into customer activity, transaction performance, loan distribution, and branch performance through dynamic visualizations and KPI cards.

The dashboard enables users to analyze banking operations using interactive filters and business intelligence techniques.

---

## 🎯 Objectives

- Analyze customer and transaction data.
- Monitor loan distribution across different loan types.
- Compare branch-wise transaction performance.
- Track monthly transaction trends.
- Identify flagged transactions.
- Build an interactive dashboard for business decision-making.

---

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

---

## 📊 Dashboard Features

### KPI Cards
- Total Customers
- Total Transaction Amount
- Total Loan Amount
- Total Transactions
- Flagged Transactions

### Interactive Filters
- Transaction Date
- City
- Customer Segment

### Visualizations
- Top 5 Branches by Transaction Amount
- Loan Distribution by Loan Type
- Monthly Transaction Trend
- Transaction Amount by Transaction Type
